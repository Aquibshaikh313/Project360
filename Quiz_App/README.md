# 🧠 Quiz App

A responsive Quiz Application built using **HTML**, **CSS**, and **Vanilla JavaScript**.

The application dynamically loads questions from a JSON file using the Fetch API and provides an interactive quiz experience with score tracking, progress updates, and instant answer feedback.

---

## ✨ Features

- Dynamic question loading using Fetch API
- Questions stored in a JSON file
- Progress bar with question tracking
- Instant correct/wrong answer feedback
- Score calculation
- Accuracy percentage
- Restart quiz functionality
- Basic error handling for failed data loading
- Responsive user interface

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- JSON
